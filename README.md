# InsertPage — Supernote PDF Plugin

**Current beta: v0.2.5**

InsertPage is a Supernote plugin for editing PDF pages directly on the device. It has been tested on a Supernote Manta running Chauvet 3.29.45 beta.

## Improvements in v0.2.5

- Much faster page insertion and deletion.
- Commands respond with a single press.
- Improved, clearer user interface.
- A close button makes it easy to return to the PDF.
- Four inserted-page styles: blank, lined, dotted, and squared.
- Faster PDF file picker.
- Options remain readable over heavily printed pages because the underlying page is faded.
- Restored application icon.

## Features

- Insert a new page into a PDF.
- Delete the current page.
- Undo the last page insertion or deletion.
- Select another PDF and insert a page from it.

## Installation

Download **InsertPage-v0.2.5-beta.snplg** from this repository or from the latest GitHub release, then install it using the Supernote plugin installation system.

## Beta status

This is beta software. It is sensible to test it with a copy of an important PDF before using it on the original file. Behaviour may vary on other Supernote models or firmware versions.

## Feedback

Testing and feedback are very welcome, particularly from users trying the plugin on other Supernote models or firmware versions.
